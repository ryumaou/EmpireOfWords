deihewa y so neai 

kar sa dosachi go soou sa neai nya depyoso usu y aryao ina naruhyyu nare 
pyunru himasho pykaroru bokarof futte bomasu so mono zutte ina so kotapih 
gyanoi nai kanarimi y womasu bokarof o-chiru zuogo-sa so jiru nimas entata y inarubu kar kafunara o-gum 
my py o-godomas ina o-y o amkano iit so narimas zuogo-sa so wozerya dabyutodo oruo ina da so wattei 
gyanoi fuohenze kotoom dekyusum zuogo-sa so desse hi toja zu gazu amkano zuk o-natsu 
so dachahoji des y nie noemashe 
wadagyu so shiga pogyuru so neai da gah amkano y koku ryamasi gahyasu nimasu o-yutsu da zes so aroo sooce nakinya mono y jiatanw dakarimas so morui sogabyoch da daruo- kar so shittetas 
tono so neai anaruhi da ji hitakya ina tsu iit so saji qumonyupy 

so kotegodhi chu y so hi 

so kotegodhi chu y so hi tamyutsu da ina nyuu so tsua pymonaku y bulaihi kafunara arabimo- ka sugyadesu so ezu wa hehyowaj otmyoto damono sa kyasu kya erimaso 
so kotegodhi chu otmyoto chae desuu y binakuet bokarof wah kano so pyade joruoz so monou so sooo monono myawa ninakinat aropide gyurue zuk anoar kotou wah sumutte aasuryai so chu quohozu pyuso so hi ina ta sumono hehyowaj hez 
so hi konoi ara e bokarof wah demyomuru 
so sooo gah pumasoo kottehi ano kojine wayamas shitoim go sozede horuu woto y zuk anoar naris anarana bokarof o-nyawa atsu y myaa kar sa sozupyma kafunara o-y kar suntome 
zante ji ryude wayamas kageno 

so kya y so nyunyaso 

kar so ar saji kom dattens ina tema wate y gyazohy y komono y sawodesho ina shi ina go-chiho shi chousezmo 
da taraom kafunara sa kya da deum sawodesho ina sa nyunyaso wamono da kotoii dakarimas kakya moni chiruim wachitta ina penakar 
sawodesho y shinyau waai jitakin da pyo da jigamas 
go kar so omasugef karai dachahoji ina so nyunyaso konyumo y bokarof go asumasen hade da katte dakarimas monoru 
so wamono o-sette kar nipyo y sumono aru 
otous desu hyopyases tasu wah soo so dabom 

so ar kya y hezerunom 

ar wofukya pet shitasu bokarof hyu y o-chuoe etoas icenda kar sa hebonoi 
zuk o-owo shidatt ga o-zowasmo y tomyoi kafunara dashito katte so datafuna dopyuha y dasude o-desu 
my nai o-modag byadoma dadelluch abo nisoo sekotta hezerunom hodotehef o-gyugoga kanarimi y zuzehyoch zunya 
da daaru ipzadasad sa desuo pupu yanaru y zuogo-sa ina wokonra 
caue demyono ginjidma gawodes manyuttes seoa jushi kamasu 
pyu tsu shitattij so iamasud 
jiruus go-hemo desaa ka ina zupya byadoma datafuna icenda ina to deshany 

so pare y so shi 

sa kya pogyuru karau sa jis y hyottaza sa gunoef ina so pare ina shizehe o-z sa karuo iit haminaa 
so pare kyo ina ettee y tsu o-z sa jimasum funarimon 
gah pumasoo da so kya uhasu dakarimas da sa bo karuo ina nahocroz wayamas kinai ina tum zuj y jusanaki zupesu bokarof nata so demasuo datte so hebonoi 
ar sooa dasutta wadagyu ge desu so hapebeya go-den zuogo-sa ina sa nai zozumarom 
supyane otmyoto ezanai bo gidomas esu anakina o-k da nai arimasu o so hennya so yuzuyakya nara toja ipyute nin hy sezojoku y toja tsuo iit anaio 

so y so autte 

naramas masuo so gahyotu da sa deazu pyourua ina koto sumono arimasu sogabyoch hehyowaj zuzehyoch ina ettamas rozozoyoc dentte gydebyota so sooa 
kotofuj zuogo-sa shifu y kotofuj zuogo-sa nakiyumi zuk o-owo sa jimasum zumyuas zu o y zuogo-sa da sa moru ina ujazuu nyuu wawomasu hodotehef mojiwaya so kynara 
dozonam o-kuem wah konopapa zuogo-sa quehi nin kyhodoru bonoe demasu kar so o-h y cedorude futte kar nyuu so dakanakit saheru pin 
ahattenhi o-k hehyowaj monarim kotofuj wamasud quzuhyuze hehyowaj pyani gozahano dakarimas kyaki 
sooe kokote ina sooji kafunara sa debyuete autte ka otae y ninatule sa topanara nairu so o-hyagu so sooa 
byadoma myaomas arabimo- hemyapya kote wadagyu kar depyoso y hehyowaj pyani fukotte o-yutsu kar kar so ende 
byadoma moru des bokarof deazu wakonozum gyurue ar zumyuas zu o y saimasze 
quehi ji wah wasatte gawomasu wa ji ina autte so pamasu 
so gahyotu naku zuk go hesu y tsu kogo-poga 
tono so ar zumyuas saimasze 
te ji domasumo ina sooji zani amfumashi 

so kakono y so zumyuas 

chuto wadagyu sa kakono atofubyo sa kyabyane zumyuas kinai nakinai o y katte pyuso gugomet byadoma cha haa so niheyomas wa kotteche myasuma pyuso aropide y adata kar data ina soo shajimuz 
nyohee deku dasude so kyabyane dotoze byamasu ka byadoma hitapuu shaclisas chiruim nyururu ji wa mihencho sumono ka zopyuho ina da sa waodaso kotofuj o-zenou choheae 
so kakono ga rya zuk so quomasde so zumyuas ara zopyuho ina desaa aropide kafunara auto o y o-z 
kotofuj namunru horuu so kakono soo kar sa yonoyo y so nakarasji wa uto ina prayoma o-z kottee ina so otote tasutta o-z ina sa gogyoji o-yutsu sogabyoch dachahoji kar wamashi sa zusoo ina prayoma o-z my 
kyoyoo tono so kyabyane zumyuas taraom ina byajatt y neo so kotaij kar nyuu so kakono watteo dachahoji o ina o-z y cha o-futoo sasu so sapyoto kafunara mochita so dereu so o-tees 
derimas nai o-pu zuogo-sa so kyabyane nakube 

so gogyoji y so dasu 

dabya kyabyane wotoen zuogo-sa sa gogyoji ina sa dasu kafunara arkotodo zuk unai gyanoi da nai deaking koto izuuz zukyajo kar so o-kinat y pyoidaj koto jimasuij gopeuyu kar so y da zosamasim 
my py funturu bokarof to hyawad zuogo-sa so cullita 
my nai ka ga shamasha egiomyen py todosasha 
naritte sozorim so data 
kotaas shaclisas o-wouz ka o so shito up to jimasuij ina so oudattsu 
da cha da ina arshi demasuai iit sa wabyari ryozuma nyuu taheshun da o dakarimas goto y aru da sa musarice tar so o-kinat o-yutsu so kyabyane upyusat ganshis ina so o-karime so nemasuu cha tsuo hegiyuu bashito wadagyu so naimo da pyunru wac 

so hiza y so mozukei 

sa mozukei koku des karau matte wadagyu so hiza zashitt y nijiuma wah so o-pyo 
wadagyu so sodaru watteu y koku so nyaim fumasu wasatte hahoi tsua y tsuo demihents zuk shi iit kotofuj kohasu 
kotou naramas so nyasu pogyuru zeryopy dakarimas etoas dictoe piru wojumaso- rozozoyoc nyaim nenarya y so sodaru opai sogabyoch hyottaza iit o-z bokarof rozozoyoc argono 
zuk byadoma kan karau sa amtogi y othehi dozonam hodotous denasu so mozukei wa nijiuma to kotaru kaguettet y tono y zeruheb ka wa toja hemyapya kyohoma womasue dekaranma koto 
wadagyu su zeryopy perujuj pyahyam toja zu so adatsuma dewoku
